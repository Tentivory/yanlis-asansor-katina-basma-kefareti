# Yanlış Asansör Katına Basma Kefareti

> Bu yazılım, insanlığın en küçük ama en utandırıcı felaketini çözer: **asansörde yanlış kata basmak**.

Bilim insanları yıllardır “asansör pişmanlık katsayısı” üzerine çalışıyordu. Biz çözdük. Artık yanlış kata basan her vatandaş, kaç merdiven, kaç çay ve kaç resmi özür mektubu borçlu olduğunu saniyeler içinde öğrenir.

## Kurulum

```bash
python3 kefaret.py
```

Bağımlılık yok. Vicdan yeter.

## Kullanım

Program size üç şey sorar:
1. Hangi kata gitmek istiyordunuz?
2. Hangi kata bastınız?
3. Asansörde başka insan var mıydı? (Utanç çarpanı için kritik)

Çıktı örneği:

```
KEFARET RAPORU
Merdiven borcu: 14 basamak
Çay borcu: 2 ince belli
Resmi özür: kapıdaki aynaya 1 kez bak
Durum: vatandaşlık onurunuz kısmen iade edildi
```

## Bilimsel Temel

Formül:

```
kefaret = |hedef - basilan| * (1 + utanç) * çay_sabiti
```

Çay sabiti `1.7` olarak TentiAŞ laboratuvarında 3 bardak çay eşliğinde ölçülmüştür. Hata payı ± bir simit.

## Sık Sorulan Sorular

**Bodrum kata basarsam?**  
Kefaret ikiye katlanır. Bodrum bir hatadır, bir kader değildir.

**Asansör yoksa?**  
O zaman zaten merdiven çıkıyorsunuz. Tebrikler, vicdanınız temiz.

**Bu proje neden var?**  
Çünkü var olmaması daha mantıksızdı.
